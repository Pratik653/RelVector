# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good faith, and do not harass anyone.
Disagreements about technical decisions are welcome; personal attacks are not.

## Reporting

Report unacceptable behaviour privately to the maintainers through the contact listed on
the repository owner's GitHub profile, or through GitHub's private reporting features.
Reports are handled confidentially. Maintainers may remove, edit or reject contributions and
temporarily or permanently ban contributors whose behaviour violates this code.
